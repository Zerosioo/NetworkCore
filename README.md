# Network Core
Hypixel's Proxy recreation attempt in BungeeCord. Might not be the cleanest but works, originally my intention was
to just see if i can recreate Hypixel's Proxy features. I am currently working on a better more optimized and cleaner
version made in Velocity.

## Features:
- Guilds
- Friends
- Parties
- Punishments
- Authentication
- Chat modes (for example guild chat, party chat, etc)
- Synchronisation (coming soon)
- API (coming soon)
## Commands:
- `/guild`
- `/friend`
- `/party`
- `/chat`
- `/reply <player> <message>`
- `/message <player> <message>`
- `/switchserver <server id>`
- `/guildchat`
- `/rank <player> <rank>`
- `/maintenance`
- `/ignore <player`
- `/unignore <player>`
- `/lobby`
- `/staff`
- `/staffchat`
- `/debug`
- `/networkreload`
- `/partychat`
- `/ping`
- `/login <password>`
- `/register <password>`
- `/changepassword <old password> <new password>`
- `/premium`
- `/mute <player> <duration>`
- `/unmute <player>`
- `/ban <player> <reason>`
